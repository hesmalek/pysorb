# PySorb GUI Executable

The standalone Windows GUI executable for PySorb 0.2.2 should be distributed as
a GitHub release asset, not committed to the repository.

Recommended asset name:

```text
pysorb-0.2.2-windows-gui.zip
```

The ZIP can include:

- `pysorb 0.2.2.exe`
- saved example sessions from `../sessions/`
- short instructions for launching the GUI

This keeps the source repository and PyPI package small while still making the
GUI available to users.
